## Named tests (in `settings.test.ts`)

1. **Default-off**: with no `CURALINA_*` env vars set, `AiServicesSettings.enabled === false`.
2. **Explicit true**: `CURALINA_AI_SERVICES_ENABLED=true` parses to `enabled === true`.
3. **Explicit false, case-insensitive**: `CURALINA_AI_SERVICES_ENABLED=False` parses to `enabled === false`.
4. **Invalid value rejected**: `CURALINA_AI_SERVICES_ENABLED=yes` throws, and the thrown message contains the literal string `"yes"`.
5. **URL defaults**: with no override, `recommendationUrl === "http://127.0.0.1:8101"`, `variantsUrl === "http://127.0.0.1:8102"`, `roomsUrl === "http://127.0.0.1:8103"`.
6. **URL override**: `CURALINA_RECOMMENDATION_URL=http://example.test:9999` overrides the default and no other URL changes.
7. **Contract version default**: with no override, `contractVersion === "1.0"`.
8. **`isAiServicesEnabled()` reflects settings**: toggling the env var between the two calls changes the return value (construct settings fresh each call rather than caching module-level state, so this is observable in one process — if the implementation caches, this test must be able to force a fresh read, and that mechanism must be named in the completion evidence).
