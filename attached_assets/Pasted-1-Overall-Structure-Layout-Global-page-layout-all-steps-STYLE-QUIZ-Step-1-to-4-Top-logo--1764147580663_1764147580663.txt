2. Visual System (Design Tokens)
2.1 Colors (approximate usage)

You can recreate with these roles (exact hex not given, but the relationships are clear): 

STYLE QUIZ - Step 1 to 4

Backgrounds

Main page: white (#FFFFFF).

Soft section background: pale warm beige behind “Select all that apply” sections and functional feature cards.

Accent rails: a medium warm grey strip sometimes used full-width at the very top or bottom.

Text

Primary: very dark grey (not pure black) for body + headings.

Secondary: mid-grey for helper/secondary text.

Cards & overlays

Option cards with photos: full-bleed photo with a dark translucent overlay bar at the bottom (charcoal at ~60–70% opacity) with white text.

Functional feature cards: light beige fill with a slightly darker beige border.

Use no strong saturated colors except within photography; the UI itself is calm neutrals.

2.2 Typography

From appearance:

Headings / Questions

High-contrast serif (Didot/Bodoni style).

Used for:

Main question (“Which room do you dream of transforming first?”).

Section words like “Mood”, “Textures”, “Lifestyle”, “Functional Features”.

Big, elegant, generous line spacing.

Body + helper text

Clean sans serif.

Used for:

Instructions (“Choose up to 2 styles.”, “Select all that apply”).

Descriptions under each functional feature.

Top navigation menu and announcement bar.

Option labels

Often uppercase sans serif (LIVING ROOM, DINING ROOM, LIGHT NEUTRALS, etc.).

White text on dark overlays (image tiles) or dark text on light card backgrounds.

Keep 2 font families: 1 serif for drama, 1 sans for usability.

5. Implementation Checklist (so you can “replate” it)

When you brief your designer/dev, give them this list:

Global

Create a shared layout with:

Fixed header (logo, nav, icons).

Announcement bar.

Constrained central content.

Standard footer nav (Previous/Next text links).

Use 2 fonts: a serif for headings, sans serif for everything else.

Color tokens

bg-page: #FFFFFF

bg-section: warm light beige

bg-accent-rail: medium warm grey

text-primary: very dark grey

text-secondary: mid-grey

card-bg: light beige

card-border: slightly darker beige

overlay-dark: charcoal with ~60–70% opacity

text-on-overlay: white

Components

PhotoTile: image + bottom overlay label.

StyleRow: (image interior + image materials).

PaletteTile: image board + label.

TagPill: pill selection for words/moods.

IconCard: icon + title + description.

NumberPillGroup: for seating / size selections.

Interactions

Multi-step form, Steps 1–7 (we visually see 1–4).

Progress label “Step X of 7” only; no progress bar.

Save state between steps.

Max/min selections enforced (e.g., up to 2).

Responsiveness

On desktop: keep multi-column grids (e.g., 4 room tiles in a row).

On mobile:

Stack tiles 1 per row.
