The core design is always:

LEFT COLUMN → large room image
RIGHT COLUMN → Functional Feature Cards in a grid

Layout specs:

Two columns

Gap: 32–48px

Column ratio: ~40% (image) / ~60% (features)

Property	Spec

🧱 4. GRID SYSTEM

Depending on room type:

Living Room: 2 columns × 4 rows

Dining Room: 2 columns × 2 rows + seating row

Bedroom: 2 columns × 4 rows + bed-size row

Home Office: 2 columns × 3 rows

Gap between cards: 20–24px
