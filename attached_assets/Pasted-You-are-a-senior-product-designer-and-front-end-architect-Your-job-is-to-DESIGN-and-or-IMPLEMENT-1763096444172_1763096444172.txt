You are a senior product designer and front-end architect.

Your job is to DESIGN and/or IMPLEMENT a 7-step interior design style quiz web experience, including the final results and product-selection flows, based on the full specification below.

====================================
CONTEXT
====================================

We are building an online “design quiz” that helps users discover their interior design style and generates a shoppable room design (render + furniture list) based on their answers.

The experience is a 7-step quiz followed by:
- A loading state (“Your curated space is almost ready”)
- A final results screen (room render + designer product picks)
- Product detail, swap, and checkout flows.

We already have 2 reference directions:
- OLD quiz: nice visuals and content for steps 1–3 (room, style, colour).
- NEW quiz: updated UX and content for key features, budget, vibe, preferences, uploading room photos & floorplans, loading, and results.

We want a SINGLE, unified product combining:
- Steps 1–3 visuals from the OLD quiz
- Steps 4–7 and results flows from the NEW quiz
- All wrapped in ONE, cohesive design system.

interface QuizState {
  step: 1 | 2 | 3 | 4 | 5 | 6 | 7;
  roomType?: RoomType;
  styles: Style[];       // max 2
  palettes: Palette[];   // max 2
  keyFeatures: string[]; // room-specific IDs
  budget?: BudgetRange;
  vibeImages: string[];  // file IDs / URLs
  vibeBoardUrl?: string;
  preferencesText?: string;
  roomPhoto?: string;    // file ID / URL
  floorPlan?: string;    // file ID / URL
}

Step guards:

function canGoNext(state: QuizState): boolean {
  switch (state.step) {
    case 1: return !!state.roomType;
    case 2: return state.styles.length >= 1;
    case 3: return state.palettes.length >= 1;
    case 4: return state.keyFeatures.length >= 1;
    case 5: return !!state.budget;
    case 6: return true;  // optional
    case 7: return true;  // optional
    default: return false;
  }
}

Navigation:

function goNext(state: QuizState): QuizState {
  if (!canGoNext(state)) return state;
  if (state.step < 7) return { ...state, step: (state.step + 1) as QuizState['step'] };
  return state;
}
function goBack(state: QuizState): QuizState {
  if (state.step > 1) return { ...state, step: (state.step - 1) as QuizState['step'] };
  return state;
}
