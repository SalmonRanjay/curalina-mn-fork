🏗️ Architecture Overview
Curalina AI is a full-stack interior design platform that combines:

AI-powered room rendering using Stability AI SDXL
E-commerce marketplace for furniture products
Design quiz to capture user preferences
Payment processing via Stripe
Object storage for images and assets

🗄️ Database Schema
Tables Overview
1. Categories - Product categorization
{
  id: uuid (PK)
  name: string
  type: 'room' | 'furniture'
  slug: string (unique)
}

2. Vendors - Furniture suppliers
{
  id: uuid (PK)
  name: string
  email: string
  createdAt: timestamp
}

3. Products - Product catalog
{
  id: uuid (PK)
  sku: string (unique)
  name: string
  description: text
  categoryId: uuid (FK → categories)
  styleTags: string[] // ['modern', 'organic']
  colors: string[]
  materials: string[]
  dimensions: { w, d, h, unit }
  price: decimal
  discount: decimal
  availability: 'in_stock' | 'preorder'
  images: string[] // URLs to images
  asset3dUrl: string // .glb or .usdz for AR
  vendorId: uuid (FK → vendors)
  shipping: { cost, eta }
  seoMeta: { title, description }
  slug: string (unique)
  createdAt: timestamp
}

4. Quiz Responses - User design preferences
{
  id: uuid (PK)
  sessionId: string // Anonymous user tracking
  roomType: string // 'Living Room', 'Bedroom', etc.
  style: string // 'Midcentury Scandi', etc.
  keyFeatures: string[] // ['Comfortable Seat', 'Storage']
  budgetRange: string // '$2K-$5K', etc.
  vibeImages: string[] // User-uploaded reference images
  preferences: string[] // Design preference bullets
  floorplanUrl: string // Uploaded floorplan image
  createdAt: timestamp
}

5. Renders - AI-generated room designs
{
  id: uuid (PK)
  quizResponseId: uuid (FK → quizResponses)
  sessionId: string
  imageUrl: string // Public URL to generated render
  prompt: string // Full AI prompt used
  productSkus: string[] // Products featured in render
  status: 'generating' | 'completed' | 'failed'
  createdAt: timestamp
}

6. Cart Items - Shopping cart
{
  id: uuid (PK)
  sessionId: string
  productId: uuid (FK → products)
  quantity: integer
  createdAt: timestamp
}

7. Orders - Purchase orders
{
  id: uuid (PK)
  sessionId: string
  status: 'pending' | 'paid' | 'fulfilled' | 'shipped' | 'delivered'
  totalAmount: decimal
  customerEmail: string
  customerName: string
  shippingAddress: {
    street, city, state, zip, country
  }
  stripePaymentIntentId: string
  createdAt: timestamp
  updatedAt: timestamp
}

8. Order Items - Individual items in orders
{
  id: uuid (PK)
  orderId: uuid (FK → orders)
  productId: uuid (FK → products)
  quantity: integer
  priceAtPurchase: decimal // Price snapshot at purchase time
}

🔌 Backend API
File Upload Endpoints
POST /api/upload
Upload files to object storage

// Request (multipart/form-data)
{
  file: File,
  folder?: string // Default: 'uploads'
}
// Response
{
  url: string // Public URL to uploaded file
}

GET /public-objects/:filePath(*)
Serve public assets from object storage

// Example
GET /public-objects/floorplans/123456789-plan.png

Product Endpoints
GET /api/products
List all products with optional filters

// Query params
?categoryId=uuid
&styleTags=modern,organic
// Response
Product[]

GET /api/products/:id
Get single product details

// Response
Product

GET /api/products/alternatives/:id
Get similar products for swapping

// Response
Product[] // Max 6 products with same category & style tags

Quiz & Render Endpoints
POST /api/quiz
Submit quiz responses

// Request
{
  sessionId: string,
  roomType: string,
  style: string,
  keyFeatures: string[],
  budgetRange: string,
  vibeImages: string[],
  preferences: string[],
  floorplanUrl?: string
}
// Response
QuizResponse

POST /api/render
Generate AI render (async)

// Request
{
  quizResponseId: string,
  productSkus?: string[]
}
// Response (immediate)
{
  id: string,
  status: 'generating',
  prompt: string,
  ...
}
// Background process:
// 1. Build prompt from quiz data
// 2. Call Stability AI API
// 3. Upload render to object storage
// 4. Update status to 'completed' or 'failed'

GET /api/render/latest?sessionId=xyz
Get most recent render for session

// Response
Render

GET /api/render/:id
Get render by ID

// Response
Render

🤖 AI Integration
Stability AI Service
File: server/stabilityAI.ts

Initialization
constructor() {
  this.apiKey = process.env.STABILITY_API_KEY;
  this.apiHost = "https://api.stability.ai";
}

Prompt Building
buildPromptFromQuiz(quizData) {
  // Maps quiz data to detailed AI prompt
  
  Style descriptions:
  - "Midcentury Scandi" → "mid-century Scandinavian design with clean lines, organic shapes, teak wood..."
  - "Organic Modern" → "organic modern style with natural materials, curved forms..."
  
  Format:
  "Photorealistic interior design photograph of a {roomType} in {styleDesc}. 
   Features include: {keyFeatures}. 
   Design preferences: {preferences}. 
   Professional interior photography, natural lighting, wide angle view, 8K resolution..."
}

Image Generation
async generateRoomRender(prompt, renderId, floorplanUrl?) {
  // Text-to-Image (no floorplan)
  Endpoint: /v1/generation/stable-diffusion-xl-1024-v1-0/text-to-image
  Settings:
  - Size: 1024x1024
  - Steps: 30
  - CFG Scale: 7
  - Style Preset: photographic
  
  // Image-to-Image (with floorplan)
  Endpoint: /v1/generation/stable-diffusion-xl-1024-v1-0/image-to-image
  Settings:
  - init_image: base64 encoded floorplan
  - image_strength: 0.35 (preserves 65% of layout)
  - Steps: 40
  - CFG Scale: 7
  
  // Upload result to object storage
  Path: /public-objects/renders/{renderId}.png
  
  Return: Public URL to render
}

Negative Prompt
"blurry, bad quality, distorted, unrealistic, cartoon, anime, sketch, low resolution"

🔄 User Flow
Complete Journey
1. Landing (/quiz)
   ↓ Complete 7-step quiz
   
2. Submit Quiz
   ↓ POST /api/quiz → Save to database
   ↓ Generate sessionId & quizResponseId
   
3. Loading Screen (/loading)
   ↓ POST /api/render → Start AI generation
   ↓ Background: Stability AI generates image
   ↓ Background: Upload to object storage
   ↓ Background: Update render status
   
4. Results Page (/results)
   ↓ GET /api/render/latest → Fetch completed render
   ↓ GET /api/products → Show featured products
   ↓ Click product → Open swap modal
   ↓ GET /api/products/alternatives/:id
   ↓ POST /api/cart → Add to cart
   
5. Cart Page (/cart)
   ↓ GET /api/cart/:sessionId
   ↓ PATCH /api/cart/:id → Update quantities
   ↓ DELETE /api/cart/:id → Remove items
   
6. Checkout Page (/checkout)
   ↓ Fill contact & shipping info
   ↓ POST /api/orders → Create order
   ↓ POST /api/stripe/create-payment-intent (future)
   ↓ Process payment
   
7. Confirmation
   ✅ Order complete
